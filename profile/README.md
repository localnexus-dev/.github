# LocalNexus

**Control center for local PHP web development environments on Windows.**
*Kontrollzentrum für lokale PHP-Entwicklungsumgebungen unter Windows.*

---

## English

LocalNexus sits above the local stack you already use — WampServer, Laragon,
XAMPP or Docker — and gives you a single place to see what is running, what is
not, and why.

When Apache refuses to start, the useful answer is not "service failed to
start." It is which config line, which port, which process is holding it.
That is what LocalNexus is built to tell you.

**What it does**

- Detects and manages your installed local stacks side by side, without
  replacing them
- Diagnoses service and configuration failures with the actual cause, not a
  generic error
- Keeps project, host and certificate setup consistent across environments
- Runs entirely on your machine — no cloud account, no telemetry requirement

**Who it is for**

Freelancers and small web agencies running several client projects on one
Windows machine, who lose hours to environment problems that have nothing to
do with the code they were hired to write.

**Status**

In active development. Not yet publicly released. This organization is the
home of the project's public repositories as they are opened.

## Deutsch

LocalNexus legt sich über den lokalen Stack, den du ohnehin benutzt —
WampServer, Laragon, XAMPP oder Docker — und gibt dir eine Stelle, an der du
siehst, was läuft, was nicht läuft und warum.

Wenn Apache nicht startet, hilft „Dienst konnte nicht gestartet werden" nicht
weiter. Hilfreich ist: welche Konfigurationszeile, welcher Port, welcher
Prozess blockiert. Genau dafür ist LocalNexus gebaut.

**Was es tut**

- Erkennt und verwaltet die installierten lokalen Stacks nebeneinander, ohne
  sie zu ersetzen
- Diagnostiziert Dienst- und Konfigurationsfehler mit der tatsächlichen
  Ursache statt mit einer generischen Meldung
- Hält Projekt-, Host- und Zertifikatseinrichtung über Umgebungen hinweg
  konsistent
- Läuft vollständig lokal — kein Cloud-Konto, keine Telemetriepflicht

**Für wen**

Freelancer und kleine Webagenturen, die mehrere Kundenprojekte auf einem
Windows-Rechner betreiben und Stunden an Umgebungsproblemen verlieren, die
mit dem eigentlichen Auftrag nichts zu tun haben.

**Stand**

In aktiver Entwicklung, noch nicht veröffentlicht. Diese Organisation ist der
Ort für die öffentlichen Repositories des Projekts, sobald sie geöffnet werden.
